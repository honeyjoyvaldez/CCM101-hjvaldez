# Laboratory Activity 1: Mission 1 - Welcome to the Cloud

## Mission Overview
As a newly accepted Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies, this mission focuses on establishing a professional technical workspace, mastering the Linux environment, and initializing a version-controlled Cloud Computing Portfolio on GitHub.

## Objectives
* Access and utilize a cloud-based Linux environment through KillerCoda.
* Explore and navigate the Linux operating system file structure[cite: 1, 2].
* Gather critical system specifications (OS, Kernel, CPU, Memory, and Disk Space)[cite: 1, 2].
* Create and organize local directories and Markdown documentation[cite: 1, 2].
* Establish a public, structured GitHub repository[cite: 1, 2].

## Activities Performed
1. **Environment Setup & User Management:** Launched an Ubuntu 24.04 KillerCoda playground, created a new user account with sudo privileges, and verified current system variables (`whoami`, `pwd`, `hostname`)[cite: 1, 2].
2. **System Investigation:** Inspected environment parameters including distribution details, kernel version, and available memory/storage resources[cite: 1, 2].
3. **Workspace Organization:** Generated standard directory structures (`Documents`, `Notes`, `Reports`, `Screenshots`) and authored an `about-me.md` profile[cite: 1, 2].
4. **Portfolio Initialization:** Created a public GitHub repository named `CCM101-hjvaldez` to house semester lab deliverables[cite: 1, 2].

## Linux Commands Used
* `sudo useradd` - Creates a new user account[cite: 1, 2].
* `sudo passwd` - Sets or updates a user password[cite: 1, 2].
* `sudo usermod` - Modifies user account properties and group memberships[cite: 1, 2].
* `su -` - Switches the active user session[cite: 1, 2].
* `uname -r` - Displays the system kernel version[cite: 1, 2].
* `lscpu` - Displays CPU architecture information[cite: 1, 2].
* `free -h` - Shows total and available system memory in human-readable format[cite: 1, 2].
* `df -h` - Reports available disk space usage[cite: 1, 2].
* `mkdir` - Creates new directories[cite: 1, 2].

* Utilizing Git and GitHub for version control and portfolio management[cite: 1, 2].
