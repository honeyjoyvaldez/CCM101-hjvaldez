# Laboratory 09: The Cloud Automation Engineer

## Mission Overview
As a member of the Cloud Automation and DevOps Team at CloudNova Technologies, this laboratory focuses on eliminating human error and scaling cloud operations by implementing Bash shell scripting, automated directory compression, and Linux Cron job scheduling.

## Objectives
* Understand fundamental Bash shell script syntax, variables, and shebang declarations.
* Use command-line text editors (`nano`) to write and save executable code.
* Modify Linux file permissions using `chmod +x`.
* Configure recurring task scheduling using the Linux `crontab`.
* Document automation workflows using Markdown.

## Commands Executed
* `mkdir app-data`
* `echo "This is critical client data." > app-data/data.txt`
* `nano backup.sh`
* `chmod +x backup.sh`
* `./backup.sh`
* `ls -l backups/`
* `crontab -l`
* `env EDITOR=nano crontab -e`

## Skills Learned
* Writing, formatting, and executing functional Bash automation scripts.
* Managing file permissions and creating timestamped system archives.
* Automating recurring operational tasks using Linux cron schedule syntax.
