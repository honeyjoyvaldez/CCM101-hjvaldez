# Checkpoint 7: Mission Reflection

### 1. Which cloud infrastructure component do you think is the most important? Why?
Networking is arguably the most vital cloud infrastructure component. While compute and storage house application logic and persistent data, networking provides the connectivity layer that enables access. Without Virtual Private Clouds (VPCs), subnets, routing tables, and security gateways, compute and storage resources remain completely isolated and inaccessible to end-users or dependent microservices.

### 2. How does Linux support cloud computing?
Linux forms the foundational operating system backbone for cloud computing environments due to its lightweight kernel architecture, high stability, open-source customizability, and efficient command-line management. Major public cloud providers run the vast majority of their infrastructure, virtual instances, container environments (like Docker and Kubernetes), and serverless architectures natively on Linux distributions.

### 3. Why is technical documentation important before deploying infrastructure?
Technical documentation establishes a standardized blueprint that prevents configuration drift, reduces operational downtime, and streamlines collaboration. Documenting system specifications, network topologies, and command workflows beforehand ensures that cloud infrastructure can be reliably audited, reproduced, and scaled across teams while maintaining strict security compliance.
