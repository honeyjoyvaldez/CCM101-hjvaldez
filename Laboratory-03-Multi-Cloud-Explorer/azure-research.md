# Microsoft Azure Research

## Brief Overview
Introduced by Microsoft in 2010, Azure is an enterprise-grade cloud computing platform tailored heavily for organizations leveraging Windows-based infrastructure and hybrid cloud deployments.

## Global Infrastructure
* **Regions:** 60+ regions worldwide, surpassing most competitors in physical country compliance coverage.
* **Availability Zones:** Paired regions and availability zones ensuring high availability and disaster recovery.
* **Edge Locations:** Extensive edge network delivering low-latency content globally.

## Cloud Management Console
Azure features the Azure Portal web console, Azure CLI, Azure Cloud Shell, and ARM (Azure Resource Manager) templates for deployment automation.

## Four (4) Core Services
1. **Compute:** Azure Virtual Machines and Azure App Service.
2. **Storage:** Azure Blob Storage and Azure Files.
3. **Networking:** Azure Virtual Network (VNet) and Azure ExpressRoute.
4. **Database:** Azure SQL Database and Azure Cosmos DB.

## Three (3) Advantages
1. Seamless integration with legacy Microsoft products (Windows Server, Active Directory, M365).
2. Industry leader in hybrid cloud solutions via Azure Arc.
3. Strong enterprise licensing flexibility and compliance guarantees.

## Typical Enterprise Use Cases
* Hybrid cloud environments connecting on-premise datacenters to the cloud.
* Enterprise identity and access management using Microsoft Entra ID.
* Corporate web apps and enterprise .NET applications.
