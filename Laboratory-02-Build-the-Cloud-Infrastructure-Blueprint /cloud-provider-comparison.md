# Core Infrastructure Services Comparison: AWS vs. Azure vs. GCP

## Cloud Service Comparison Matrix

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon Elastic Compute Cloud (EC2) | Azure Virtual Machines | Google Compute Engine (GCE) |
| **Storage** | Amazon Simple Storage Service (S3) / Amazon EBS | Azure Blob Storage / Azure Managed Disks | Google Cloud Storage / Google Persistent Disk |
| **Networking** | Amazon Virtual Private Cloud (VPC) | Azure Virtual Network (VNet) | Google Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS Identity and Access Management (IAM) | Microsoft Entra ID (formerly Azure Active Directory) | Google Cloud Identity and Access Management (IAM) |

## Guide Questions & Analysis

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest range and deepest catalog of cloud services, boasting over 200 fully featured services. Having entered the market first in 2006, AWS has built an extensive global ecosystem spanning specialized areas such as edge computing, quantum computing, satellite management, and specialized database engines. This maturity and feature density give AWS unmatched versatility across complex enterprise application architectures.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is the best recommendation for a Microsoft-centric organization due to its seamless native integration with existing enterprise software. Azure allows companies to easily federate identity management using Microsoft Entra ID and extends support for Microsoft 365, Windows Server, and SQL Server licensing through Azure Hybrid Benefit. This native ecosystem synergy drastically reduces implementation overhead, operational complexity, and licensing costs compared to alternative cloud platforms.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized for its innovation in AI, ML, and Kubernetes services. Because Google originally created and open-sourced Kubernetes, Google Kubernetes Engine (GKE) is considered the industry standard for managed container orchestration. Additionally, GCP leads in data analytics and artificial intelligence by leveraging core models and tools such as Vertex AI, BigQuery, and custom TPU hardware infrastructure.

### 4. What similarities did you observe among the three cloud providers?
All three cloud providers offer equivalent foundational infrastructure services covering core compute, persistent block/object storage, isolated virtual networking, and identity management. They each utilize global network regions with multiple availability zones to ensure fault tolerance, high availability, and localized data compliance. Furthermore, all three operate under a pay-as-you-go pricing model with options for sustained or committed usage discounts.
